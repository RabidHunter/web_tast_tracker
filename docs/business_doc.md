# Бізнес-документ: Task Tracker

## 1. Назва системи й короткий опис
**Task Tracker** — це веб-застосунок для управління особистими завданнями. Система дозволяє користувачам зручно планувати свій час, створюючи список справ, відстежуючи їх статус та організовуючи робочий процес. 

Головна мета застосунку — надати мінімалістичний та швидкий інтерфейс для контролю за щоденними задачами, уникаючи перевантаженості зайвим функціоналом.

## 2. Ролі користувачів
Оскільки проєкт призначений для особистого використання, виділяються дві базові ролі:
* **Анонімний користувач (Гість)** — може переглядати лише головну/вітальну сторінку застосунку.
* **Авторизований користувач** — має доступ до власного списку завдань (може створювати, редагувати, видаляти та змінювати їх статус).

## 3. Основні сценарії використання (Use Cases)
1. **Реєстрація та вхід:** Користувач створює акаунт або входить за допомогою логіна/пароля.
2. **Створення завдання:** Користувач додає нове завдання до списку (вказує назву).
3. **Зміна статусу:** Користувач відмічає завдання як "виконане" (або знімає цю відмітку).
4. **Видалення завдання:** Користувач видаляє завдання зі списку, якщо воно більше не актуальне.

## 4. Функціональні вимоги
* Система повинна дозволяти створення нових користувачів та їх авторизацію.
* Система повинна підтримувати CRUD-операції (Create, Read, Update, Delete) для завдань.
* Кожне завдання повинно мати поточний статус (виконано/не виконано).
* Завдання повинні бути прив'язані до конкретного авторизованого користувача (ізоляція даних).

## 5. Нефункціональні вимоги
* **Швидкодія:** Час відповіді API не повинен перевищувати 300 мс.
* **Зручність (UI/UX):** Інтерфейс (React) має бути адаптивним та інтуїтивно зрозумілим, підтримувати миттєве оновлення статусу без перезавантаження сторінки.
* **Безпека:** Паролі користувачів повинні зберігатися у базі даних виключно у захешованому вигляді.

## 6. Обмеження (Що система точно не буде робити)
* У системі не буде функціоналу для спільної роботи команд над одним списком.
* Не буде системи пуш-сповіщень або нагадувань на email.
* Застосунок є виключно веб-орієнтованим (створення окремих нативних мобільних додатків не планується).
