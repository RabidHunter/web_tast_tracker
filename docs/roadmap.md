# Roadmap: Task Tracker

## Тиждень 3: Розширення API (Повний CRUD)
* Створити endpoint `DELETE /tasks/{id}` для видалення завдань.
* Створити endpoint `PUT /tasks/{id}` (або `PATCH`) для зміни статусу завдання (виконано/не виконано).
* Оновити React-клієнт, щоб кнопки видалення та зміни статусу викликали нові API ендпоінти.

## Тиждень 4: Базова авторизація (Auth Module)
* Додати таблицю `users` до PostgreSQL.
* Створити endpoints для реєстрації (`POST /register`) та логіну (`POST /login`).
* Налаштувати генерацію та перевірку JWT (JSON Web Tokens) на FastAPI.
* Зробити так, щоб ендпоінти завдань були доступні лише за наявності валідного токена.

## Тиждень 5: Інтеграція авторизації на клієнті та фіналізація
* Створити на React сторінки "Логін" та "Реєстрація".
* Налаштувати збереження JWT токена на клієнті (Local Storage або Cookies).
* Прив'язати завдання до конкретного користувача (показувати користувачу лише його власні таски).
