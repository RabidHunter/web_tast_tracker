# Domain Entities: Task Tracker

## Піддомени (Subdomains)
Для нашого простого трекера завдань ми виділяємо два основні піддомени:
1. **Core Domain (Основний домен): Завдання (Task Management)** — тут міститься головна бізнес-логіка (створення, відстеження статусу, управління списками).
2. **Generic Subdomain (Загальний піддомен): Користувачі (User Identity)** — відповідає за авторизацію та ідентифікацію власника завдань (буде додано в наступних практичних).

---

## Ключові сутності (Entities)

### Піддомен: Task Management
* **Task (Завдання)**
  * `id` (UUID або Integer) — унікальний ідентифікатор.
  * `name` (String) — назва/текст завдання.
  * `is_completed` (Boolean) — поточний статус (виконано чи ні).
  * `owner_id` (Integer) — посилання на користувача, якому належить завдання.
* **TodoList (Список завдань)** — *опціональна сутність для майбутнього*
  * `id` (Integer)
  * `title` (String)
  * `tasks` (List[Task])

### Піддомен: User Identity
* **User (Користувач)**
  * `id` (Integer) — унікальний ідентифікатор.
  * `username` (String) — логін.
  * `password_hash` (String) — зашифрований пароль.
